# AD and OIDC validation

Architecture: on-premises Active Directory → Keycloak federation → AIIT OIDC. Synthetic signed issuer and live browser fixtures cover exact issuer and audience, JWKS signature, Code+PKCE, state/nonce, secure cookies, CSRF, session expiry, and fail-closed issuer responses. PostgreSQL tests exercise digest-only sessions and identity-change revocation. The app maps verified issuer/subject to a pre-bound active local account. Current local role and SBU govern authorization.

Enterprise test prerequisites include an approved nonproduction realm and OU, restricted federation service identity, approved OIDC client and fixed callback origin, trusted CA, allowlisted flows from Keycloak to AD and AIIT to Keycloak, and synchronized clocks. The identity owner must define provisioning, entitlements, local disable propagation and session revocation. Bind identities from the verified subject using an audited procedure. Rehearse activation, role/SBU changes, AD disable while a session remains open, revocation time, rollback, and issuer outage. Collect sanitized event IDs and outcomes. Target federation is blocked pending approved access, test identities and agreed disable propagation.
