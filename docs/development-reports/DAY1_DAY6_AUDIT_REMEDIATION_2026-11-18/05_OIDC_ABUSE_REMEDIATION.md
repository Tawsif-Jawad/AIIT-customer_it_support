# OIDC abuse protection

Day 6 used an HMAC-derived bucket per IPv4 address or IPv6 /64. A distinct global counter allowed 128 login starts per 300 seconds by default, with a configured maximum of 256. A distributed client set could consume it before an employee arrived. A separate per-client callback budget and four shared per-process initiation/exchange slots applied. Forwarded addresses only gain authority through configured peers and an authenticated hop. PostgreSQL counter failure closes admission with 503, while liveness bypasses counters.

The same configured aggregate budget is divided across up to eight independently enforced groups keyed by IPv4 /24 or IPv6 /56, using the existing stable database secret. With the default, each group gets 16 starts per 300 seconds. The personal login and callback gates remain. PostgreSQL updates counters atomically and shares them across processes. Four login and four exchange operations per process are independently admitted, with existing provider timeouts and one-time state. Apply the additive constraint migration before rolling out and coordinate uniform limits across all API instances.

The two-process fixture verifies concurrent updates, per-client flooding, users sharing a flooded network group, a separate group's successful login and callback, replay/invalid callbacks, expiry recovery and database outage. The ingress suite verifies IPv4-mapped and IPv6 canonicalization, proxy spoof resistance and provider timeout. Real issuer capacity under sustained distributed load and connection use during floods remain unverified.

A sufficiently distributed adversary can still fill every group. Real employee NAT, shared prefixes and hash collisions can share a limit, and additional API processes also increase provider concurrency. Public exposure requires ingress-side quotas, connection/time limits, trusted forwarding, a deployment-approved issuer capacity envelope, and attack drills with actual employee network topology. Budget replenishment uses fixed windows, so operations can burst across rollover boundaries.
