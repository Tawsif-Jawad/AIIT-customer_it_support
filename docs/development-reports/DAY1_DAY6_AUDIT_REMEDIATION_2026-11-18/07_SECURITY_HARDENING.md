# Security and ingress

The web serves a CSP on HTML, with self-hosted scripts and a fresh nonce for the existing inline portal script and stylesheet. The policy denies framing, plugins and base URL changes, and restricts connections and form submissions to the same origin. Existing inline style attributes remain enabled. HTML responses also carry frame denial, MIME-sniffing protection and no-referrer policy. The browser regression injects an untrusted inline script and confirms the normal portal can still sign in. Existing Chromium workflows cover asset loading, navigations and identity.

Production web startup requires an HTTPS public origin and configured authenticated upstream peers. The edge owns HTTP redirection and HSTS. A disposable TLS edge with a locally trusted certificate confirms HSTS on its TLS response and absence on the web server's direct HTTP response. Production hostname, certificate, edge ACLs, proxy header scrubbing, HSTS duration, and rollout order require deployment verification. Delay includeSubDomains or preload until the hosting owner approves the affected domain tree.

The enterprise realm blueprint uses an exact loopback callback, requires S256 PKCE, and disables direct access, implicit flow and service-account grants. The local realm already enforces the exact callback and has no federation. The enterprise LDAPS blueprint stays disabled and read-only with truststore enforcement and placeholders. Real CA-chain trust, AD account mapping, credential rotation and referral behavior are pending.

Audit and log safeguards include bounded audit feed, role gating, structured redaction, generic provider errors and atomic audit writes. Existing database triggers deny ordinary audit updates, deletes and truncation. Database owners and administrators can alter the schema or disable guards. Approval events and ticket forms contain business data and need classified handling. Production requires approved log retention, export to a controlled append-only destination, encrypted backup storage, recovery access controls and restore rehearsal.
